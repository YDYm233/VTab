# V_Tab

A modern bookmark management dashboard — built with Vue 3, TypeScript, Varlet UI, Pinia, and Vue Router.

## Tech Stack

| Layer | Library |
|-------|---------|
| **Framework** | [Vue 3](https://vuejs.org/) (Composition API + `<script setup>`) |
| **Language** | TypeScript |
| **Build Tool** | [Vite](https://vitejs.dev/) |
| **UI Library** | [Varlet UI](https://varlet.gitee.io/varlet-ui/) v3.17 |
| **State Management** | [Pinia](https://pinia.vuejs.org/) |
| **Routing** | [Vue Router 4](https://router.vuejs.org/) |
| **Type Check** | vue-tsc |

## Getting Started

```bash
# install dependencies
npm install

# start dev server with hot reload (default: http://localhost:5173)
npm run dev

# build for production
npm run build

# preview production build
npm run preview
```
